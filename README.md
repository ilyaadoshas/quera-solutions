# Introduction
Solutions to coding problems from [Quera](https://quera.org/) written in `python` .

## Structure
- Solutions are based by difficulty.`easy` , `medium` and `hard` .

```
quera-solutions\
|_ easy\
|    |_ 001-yellow-question-problem.py
|
|_ medium\
|
|_ hard\
|
|_ README.md
```
Each solution contains:
- The problem link
- An simple solution
